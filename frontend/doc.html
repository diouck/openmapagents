Prise en main

🐳 Avec Docker — recommandé

# Cloner et lancer le stack complet (frontend + backend + postgres/pgvector + redis)
git clone https://github.com/diouck/openmapagents.git
cd openmapagents
cp backend/.env.example backend/.env   # renseigner au moins une clé LLM
docker compose up -d              # → http://localhost:8090

Aucune compilation : les images sont récupérées depuis GHCR (publiées par GitHub Actions). Mise à jour : docker compose pull && docker compose up -d.

💻 En local (développement)

# Backend (terminal 1)
cd backend
python3 -m venv venv && source venv/bin/activate   # Windows : venv\Scripts\activate
pip install -r requirements.txt -r requirements_agent.txt
cp .env.example .env && python agent.py        # → http://localhost:8000

# Frontend (terminal 2)
cd frontend && npm install && npm run dev       # → http://localhost:5173

La carte, les fonds OpenFreeMap et l'analyse spatiale fonctionnent sans aucune clé. Les clés ne servent qu'aux modules optionnels (agent LLM, Google Earth Engine, Mapbox, base externe).
