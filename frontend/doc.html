📖 Documentation OpenMapAgents

Guides complets, API, exemples et ressources de développement.

Installation

Prérequis

  • Python 3.10+
  • Node.js 18+
  • PostgreSQL 13+ (optionnel, pour PostGIS)

Démarrage rapide

git clone https://github.com/diouck/openmapagents
cd openmapagents
./install.sh  # ou install_deps.ps1 sur Windows
cd frontend && npm run build && cd ..
bash start.sh

L'app est disponible à http://localhost:8000.

Modules

Imagerie satellite

Données Google Earth Engine : NDVI, LST, NDWI, EVI, timelapse, détection de changement.

Données vectorielles

  • Overture Maps : 5 milliards d'objets géospatiaux via DuckDB S3.
  • OpenStreetMap : POI, routes, parcs via Overpass API.
  • PostGIS : Jointures spatiales personnalisées.

Analyse

  • Isochrones (5, 10, 15, 30 min).
  • Routing multi-mode (pied, vélo, voiture).
  • Import shapefile/GeoJSON/GPX/KML.

API & MCP

45+ outils MCP exposés directement dans Claude Desktop et Cursor via le Model Context Protocol.

Endpoints principaux

  • GET /api/config : Configuration du LLM actif.
  • GET /api/themes : Liste des thématiques.
  • POST /api/query/{theme} : Calcul d'indice ou d'analyse.
  • GET /api/h3/{theme} : Agrégation H3 spatiale.

Documentation OpenAPI complète : /api/docs (Swagger UI).

Architecture

Backend (Python/FastAPI)

  • Orchestration multi-agent avec routeur RAG.
  • Intégration Google Earth Engine + DuckDB S3.
  • MCP Server pour Claude + IDE.

Frontend (React + Vite + MapLibre)

  • Cartographie interactive avec tuiles vectorielles.
  • Chat IA en langage naturel.
  • Symbologie et légendes dynamiques.
